Section 01

Motivation

Why detecting false information requires understanding both what was said and how it spread.

Project objectives

01 · Motivation

General objective

Build a deep-learning framework that classifies false information by integrating the source post's content with the propagation structure of its information cascade.

Specific objectives

  • Engineer structural & temporal features from propagation trees
  • Implement GCN, GAT & Hybrid backbones over identical features
  • Design the original ASAG per-node gating operator
  • Evaluate with stratified 5-fold cross-validation

The core challenge

01 · Motivation

No reply text in Twitter15

Due to platform terms, only the source tweet has text. Every reply is just [user, tweet_id, delay] — no words.

A text-only model makes every reply an identical empty vector, so accuracy plateaus around 66%.

The opportunity

The discriminative signal lives in how the claim spreads — depth, timing, branching, hubs.

  • Encode the source post with a Twitter-tuned transformer
  • Describe the tree with engineered structure + timing
  • Fuse both for the final decision
Replies carry structure, not text — this is why the project is built around a graph model rather than a bigger language model.

Two ways to learn from neighbours

02 · Foundations

GCN — listen to everyone equally

Averages the neighbours (degree-normalized). Calm & stable — great at damping a flood of near-identical late retweets.

Hgcn = Â · X · W

GAT — listen more to who matters

Learns an attention weight per neighbour. Sharp & selective — spotlights the pivotal early reply.

αij = softmax(LeakyReLU(a·[Whi‖Whj]))
Analogy: GCN is a democracy (everyone votes equally); GAT is a meritocracy (better neighbours get more say).

Section 02

Proposed Method

A single gate that learns — for every node — whether to trust structure (GCN) or attention (GAT).

ASAG — per-node adaptive fusion

03 · Proposed Model
GCN output hgcn
gate α ∈ [0,1]
σ(·)
learned per node
GAT output hgat
Fused representation hi
hi = αi ⊙ hi(gcn) + (1 − αi) ⊙ hi(gat)
The gate αi is learned from node features and structure, allowing different importance for different nodes.

How does the gate choose well?

03 · Proposed Model

It learns, isn't told

Its gradient ∝ (hgat − hgcn) — the difference between branches. Every step nudges it toward whichever was more correct at that node.

Starts safe

Gate bias initialized to −0.5 (mean ≈ 0.38), so it leans on the robust GCN early and shifts to attention only where it helps.

Interpretable

The mean gate is logged, giving a readable measure of how much the model relied on structure vs attention.

Honest framing: gated GCN/GAT fusion builds on prior work (e.g. L-CAT, ICLR 2023). Our contribution is the per-node application to rumor cascades in a bidirectional model — and a controlled comparison.

Turning "no reply text" into signal

04 · Architecture

16 per-node features

time / depthout-degree subtree sizeresponse delay arrival rankleaf / root flags inter-arrival gap

Each captures when a node posted, how deep it sits, and how much reply it drew — then projected to 64-d.

12 whole-cascade features

cascade sizemax depth breadthleaf fraction timing spreadunique users

A bird's-eye summary of the whole tree, encoded to 128-d and injected before the classifier.

All features are derived only from the tree files — no external user or account metadata is collected.

Training setup & parameters

05 · Configuration

Model

  • proj 64 · hidden 128 · out 128
  • GAT / hybrid heads = 4
  • Fusion 256 · classifier in 640
  • Dropout 0.30 · DropEdge 0.20

Optimization

  • AdamW · weight decay 1e-4
  • Cosine warm restarts (T₀=50)
  • Grad-clip 1.0 · label smooth 0.05
  • Class-weighted loss

Protocol

  • Stratified 5-fold CV (seed 42)
  • 200 epochs · patience 25
  • Early-stop on macro-F1
  • Hybrid: lr 3e-4 · batch 64
All three backbones share identical features, fusion & classifier — so any difference is due to the message-passing operator alone.

How we measure performance

05 · Configuration

Metrics

  • Accuracy — overall correctness
  • Macro-F1 (primary) — averages all 4 classes equally
  • Per-class F1 — exposes the hard classes
Macro-F1 = ¼ Σ F1c,  F1c = 2PcRc / (Pc+Rc)

Why macro-F1?

The classes are imbalanced and the minority ones (False / Unverified) matter. Macro-F1 makes a rare class count as much as a common one.

Reported as mean ± std across the 5 folds, with the best checkpoint restored per fold.

Conclusion

07 · Conclusion

We combine content and propagation to detect false information.

GCN and GAT capture complementary signals in a rumor cascade.

ASAG adaptively fuses them per node, leading to the best overall performance.

Understanding how information spreads is as important as what the information says.
